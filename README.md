An original island-hopping flight game for the desktop browser: fly a small bush plane over a chain of windswept islands, thread rings, run supply sorties and land on short strips with an eye on fuel and damage. Plays offline from static files, with keyboard and mouse.

## Run it

```sh
node serve.ts            # serves game/ at http://localhost:8080
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # hand-in: copies game/ and screenshots/, writes dossier.json
```
